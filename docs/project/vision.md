# Vision

A local-first and maintainable open source voice satellite for rooted LG webOS TVs, using hardware already installed in a home.

**Primary scenario:** from the sofa, a person says a wake word to the TV without a remote, controls Home Assistant, and hears a short reply while normal TV usage is preserved.

**Secondary scenarios:** timers, announcements, screen-off voice control, optional music playback through the satellite's Home Assistant media player ([ADR 0010](../decisions/0010-music-playback.md)), and multi-TV installations.

The software is an adapter to Home Assistant, not a second smart home platform, ASR engine, or media streaming service.

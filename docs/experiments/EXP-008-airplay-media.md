# EXP-008 — AirPlay / Music Assistant integration

**Status:** NOT PLANNED (owner decision 2026-11-05: AirPlay is not used for music, [ADR 0010](../decisions/0010-music-playback.md); the text below is kept as the record) · **Risk:** reversible normal media playback

**Question:** Does Music Assistant work with the TV's existing AirPlay 2 receiver for music, including volume, resume and screen-off behavior?

**Prerequisites:** verify receiver capabilities for target model; ensure no personal accounts/tokens enter reports. Test network discovery, selecting a track, pause/resume, wake word during playback, switching HDMI/Netflix, speaker/eARC output and behavior after standby.

**Acceptance:** supported operations recorded per TV/firmware/state; short conversational TTS remains a separate native playback problem.
